Entry for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty on [make.fun](https://make.fun).

`main.py` is a deterministic program (no network, no randomness) that writes a
single original warning label to `/output/entry.txt` (or `entry.txt` beside
itself when `/output` is not present):

> WARNING: Do not alter the past. The past has a lawyer, and it has already sued you twice.

Run it with `python3 main.py`.
